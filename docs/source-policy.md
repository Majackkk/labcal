# 原件接入和证据核验

原件接入负责保存原始字节、显示名称、来源、代码、哈希和文件容器检查结果。文件存在、能够解析或能数出页数，只证明资料接入状况，不能标为技术内容已核验。

## 资料范围

允许共用的CNAS资料和计量规范进入共享参考库。说明书、证书、台账、旧方案等进入所属实验室的数据区。只有OCR而无原件的内容不能作为已核验依据；历史审核结论不自动继承为批准状态。

## 必须回到原页

编制真实方案时，关键数值、公式、单位、上下标、表格、脚注与适用条件需直接核对原页。核验记录保存实际核对的字段、页码／位置、原文和适用性说明。不将整份文件“已读”状态替代逐参数核验。

智能体可以定位、提取和起草候选要求，不能替人员填写真实核验记录或确认结论。相同原件和参数未变化时可复用有效记录；原件、参数或方案内容变化时重新核对相应关系。

## 运行资料与原件缺口

公开源码不附带标准原件、实验室资料及历史迁移状态。各工作空间使用`source gaps`查询本次用途所需的原件缺口，并记录正文完整性、修订版本及适用性核对结果。候选原件不会自动覆盖已固定的来源或标为现行有效。

## 接入命令

```bash
./labcal source add --lab LAB_ID --file 原件路径 --kind metrology_regulation --code '规范编号及版本'
./labcal source add --file 公共原件路径 --kind cnas_document --code '文件编号及版本' --shareable
./labcal source gaps --lab LAB_ID --codes '所需文件编号及版本'
```

共享范围需明确指定，实验室私有文件不能用 `--shareable` 转为公共标准。实际原件内容变化后导入为新来源；原存储对象保留，不能用新文件覆盖旧字节。
