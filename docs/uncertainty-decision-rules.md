# 校准确认中的不确定度与误差限评价

2026-11-09更新。用户要求：需要采用JJF 1094时，正式确认表必须包含对应分支的评价过程。本页接入既有confirmation分析与发布流程，不新增数据库、业务入口或限值来源，也不自动重发历史确认表。

## 先确定评价对象和依据

先执行确认表工作流中的“验收依据与器具参考的边界”。方法用途U评价与器具参考U评价分别记录；器具MPEV在本栏注明具体值、载荷和选用情形，不能仅写“见表3注”。器具U比较不自动证明方法用途符合；共用证书U不等于可以共用未经适用性确认的限值。

先按检测方法与实际用途确定技术要求，再确定如何考虑U。JJF 1094提供通用评定原则，不替检测方法、器具规格或实验室有据建立的要求生成MPE。

- `E`为本项目示值误差；`MPEV`为对应对称最大允许误差的绝对值，是正数，不是正负限之差。例如±1 mg对应MPEV=1 mg。
- `U95`为评定该示值误差的扩展不确定度，不能只取标准器的U或机构CMC。规范第5.3.1.4条注2允许在一定情况下用k=2的扩展不确定度U代替；须核对证书包含因子、包含概率及适用项目，不能将标准不确定度u或任意k的U直接代入。
- E、U和MPEV使用同一测量量、同一单位、同一点位/工况。相对量须具有相同分母。U未给出、给出“/”或不适用时，不能代为0，也不能借用其他项目的U。
- 分度值、显示/记录精度、重复性标准偏差和CMC不自动成为MPEV。缺少对应误差限时，不硬算U/MPEV；按要求的真实含义另作评价。
- 实际依据有专门判定规则时先核对并落实。采用JJF 1094、CNAS-GL015的实验室约定规则或只作补充技术比较，必须明确性质，不能从不同规则中挑选有利结果。

## JJF 1094—2002的适用分支

### 依据计量检定规程评价 第5.3.1.5条

先核实确实依据适用规程完成评定，评定方法、计量标准、环境条件满足规程及量值传递要求，器具处于正常状态。在这些前提下，规程要求的各点误差不超过相应级别的MPE，可按该条判该示值误差符合相应级别，不必再叠加U。

不能因为报告引用JJG、表中列有允差或人员选用某个JJG限值，就自动认定本分支成立；也不能把器具等级符合直接替代检测用途符合。校准按JJF进行、仅借用JJG允差作参考时，不自动享有本分支的前提。

### 一般示值误差评价 第5.3.1.4和5.3.1.6条

以下针对有明确对称误差限、采用JJF 1094相应路径的项目。令r=U95/MPEV，使用未提前舍入的值判断分支。

| 条件 | 比较方法 | JJF 1094评价结果 |
| --- | --- | --- |
| r≤1/3 | \|E\|≤MPEV | 第5.3.1.4条：示值误差合格，可不考虑该U对本次符合性判定的影响 |
| r≤1/3 | \|E\|>MPEV | 第5.3.1.4条：示值误差不合格 |
| r>1/3，且满足第5.3.1.6条适用前提 | \|E\|≤MPEV−U95，等价于\|E\|+U95≤MPEV | 第5.3.1.6 a)：合格 |
| 同上 | \|E\|≥MPEV+U95 | 第5.3.1.6 b)：不合格 |
| 同上 | MPEV−U95<\|E\|<MPEV+U95 | 第5.3.1.6 c)：处于待定区，不能下合格或不合格结论 |

第5.3.1.6条针对依据计量检定规程以外的技术规范作示值误差符合性评定，还要求采用合适的方法、计量标准及环境条件。要扩展为整个范围的符合结论，须有足够且有效覆盖该范围的点位，不能用单个点替代。只评价证书已有点位时明确本次范围，不由此自动限制设备使用。

边界依原文：r=1/3属于简化分支；\|E\|=MPEV−U95属于合格分支；\|E\|=MPEV+U95属于不合格分支。待定区两端为严格不等式。不得把“未通过合格判据”一律写成“不合格”。

第5.3.1.4条注1允许型式评价、仲裁鉴定在必要时采用1/5；它不是日常设备校准确认的默认比例。

### U接近或大于MPEV时

以下是第5.3.1.6条合格式的数学结果，不是新增的独立条款或器具禁用要求：

- U95=MPEV时，合格式只剩\|E\|=0这一边界情形。不能笼统称所有结果不合格，也不能用舍入后的零误差掩盖精度不足。
- U95>MPEV时，合格接受区为空，不能用该判据确认合格；仍按不合格式或待定区分别处理。该情况本身不证明实物超差，也不证明报告不真实。

### 不对称或单侧限值 第5.3.1.7条

原文允许按上述原则评定，但不提供把限值强行折成对称MPEV的公式。保留原来的上下限或单侧限值，按该项目适用规则比较相应不确定度区间；不擅取区间宽度一半作为MPEV，不照搬绝对值公式。具体推导、边界及规则性质留在本项目分析中。没有相应限的一侧不得补造限值。

### 按实际值不确定度划分的等别 第5.3.2条

如果评定对象是按实际值的测量不确定度划分的等别，不套用上述示值误差1/3路径。第5.3.2.1、5.3.2.2条分别要求核对实际值U是否满足相应等别限值及其他特性，适用时使用修正值或校准曲线给出值。不得从本节推断所有校准后的仪器都必须修正。

## 与CNAS-GL015:2022的关系

CNAS-GL015第6.2.1条为简单接受，第6.1和6.2.2条介绍保护带，第6.2.3条为有保护带的非二元规则。这些规则与JJF 1094第5.3.1.6条的三分支不完全相同，特别是“未进入保护带接受区”的含义不能混用。该文件附录B例1中的1/3是其示例设定，不是第6.2.1条对所有简单接受的统一前提。

实验室采用有据的CNAS简单接受并另列U评价时，补充JJF的比值或含U比较不自动修改已选规则。若明确宣称按JJF 1094评定，则必须遵守该路径的前提与分支，不能在其待定区又借简单接受宣称“按JJF合格”。规则有冲突先解决适用关系，不静默切换。

## 必须写入确认表的内容

适用性筛查在每次U评价时完成，不要求所有特性都强行采用JJF 1094。需要采用其路径的项目，在现有“不确定度信息及评价”列按下列顺序简洁填写，不增列表或单独审批：

1. **证书U**：数值、单位、k/包含概率及适用点位；非适用或未报告项如实说明。
2. **依据与适用路径**：JJF 1094—2002具体条款；MPEV的实际来源、数值及本项目适用关系。第5.3.1.5分支需说明规程及必要前提，不强加1/3复算。
3. **比值评价**：一般路径列出U95/MPEV与1/3的比较；不能只写“满足”或“不满足”。
4. **结果比较**：列出本分支实际采用的误差比较式及数值。r>1/3时必须继续完成第5.3.1.6 a)/b)/c)分支，不能止于比值。
5. **判断**：明确合格、不合格或尚不能判定该具体项目符合性；注明是正式规则还是补充技术核查。中性特性不能冒充上述合格。方法列用途判断与U列一致，不能用器具结论替代用途结论。

同一工况可合并叙述，结论相同的点位可给出经逐点核算的最不利值；U或MPE随点变化时逐点配对，不把来自不同点的最大值组合当成某点实测结果。U列不得为精简省去分支依据和必要计算。

沿用`technical_review.rules.reasoning`记录适用前提、比较量、规则及U作用，`uncertainty_quote`与`publication_review.rows.uncertainty_reasoning`摘录正式U列。这里不另建第二个可编辑限值表。

发布前人工语义核对：适用路径已明确；MPEV及U对应真实测量量；比例和边界复算正确；超过1/3已继续评价；待定没有写成超差/合格；所选规则与用途结论一致；引用条款、原页可追查。程序在下述受支持路径复算声明输入，不自动证明输入含义、依据适用性或原页正确。

## 现有发布流程中的检查

新prepare任务固定`uncertainty_review_version=1`，沿用analyze → Word → format → finish。每条`technical_review.rules.reasoning`追加一个`uncertainty_review`，不增设状态机、数据库或审批。旧任务及归档记录仍可读取；新prepare的任务要求完整评价。旧任务若主动提交该块也执行对应检查。

| 字段 | 用途 |
| --- | --- |
| route | jjf1094_general、verification_regulation、simple_acceptance、qualitative或other_documented_rule |
| application | decision为本条正式判定；supplementary为独立补充评价，不能暗改本条正式规则 |
| basis_quote | 从正式U栏摘录具体依据、适用条件及本项目关系；不能仅引用文件名 |
| calculation_quote | 从正式U栏摘录实际比较；不宜数字化时摘录不计算的具体理由及评价 |
| judgment_quote | 从正式U栏摘录明确分项结论 |
| outcome | 本条U评价的结果，沿用原有状态枚举，不新增六象限编码 |
| points | 同一固定任务内逐点计算输入：label、error、expanded_uncertainty、mpev、unit；数值用十进制字符串。qualitative及other_documented_rule为空数组，计算与判断由原页分析支持 |
| coverage_basis | jjf1094_general必须明确u95或k2_equivalent；后者的适用依据写入basis_quote |

这些数值仅是本次判定的计算证据，不能成为可编辑的实验室验收限值库，也不能反向更新方法库或方案。每条用途规则用其自身有来源的MPEV，器具MPE不得替代用途MPE；即使共用一个附页行，也逐规则配对计算。

`jjf1094_general`只支持对称MPE的示值误差，程序按3×U≤MPEV选择第5.3.1.4或第5.3.1.6路径，避免预先舍入1/3；复算包括待定区上半段和等号。`verification_regulation`核对误差列值，不额外叠加U，适用前提必须由执行智能体核实。`simple_acceptance`保留已选的直接比较规则，U另列评价。缺U不能按0进入JJF算法。

JJF一般路径作为正式规则时，既有`decision_mode=specification_check`，`uncertainty_role=decision_component`，表示U参与条件分支的选择与必要的区间比较；不是将所有点都强制套同一保护带。直接比较正式规则仍为`direct_comparison`及`separate_evaluation`。有据选择直接比较时，可把JJF一般路径作为supplementary独立核查，保留它的真实结果，不借此伪称按JJF合格。

单侧/不对称、按实际值U划分等别、其他保护带及修正后的评价使用other_documented_rule，明确具体依据、计算和结论，由执行智能体核对，不能冒充已通过上述对称误差算法。只有分度/记录精度要求、确无独立误差限、未单列适用U等情形可qualitative，必须给出实际原因；不能借该路径隐藏已有明确误差要求或真正的证据缺口。

程序阻止：缺少评价；依据/比较/结论只存内部而未进入正式U栏；分辨力或标准偏差进入误差算法；缺少U95适用声明；数值分支或结论错误；同组切换U规则；正式规则和结果状态不一致。它不从中文语句推断限值，不证明条款适用或每个原页数字抄录无误。analyze、format、finish共用检查，Word与Excel继续来自同一份五列记录。

修正使用还须核对修正值的符号、点位、工况与插值范围、修正后的剩余误差及适用U，不能宣称减去e就消除全部系统影响。最终修正选项、附页应用及总体选择保持一致；原始实测值与证书U保留，不改写为修正后的数据。CMC只用于同项目、范围、条件及k下的能力核对，不代替本机实际U或承诺机构必然达到某个U。

## 待定区处理

按第5.3.1.6 c)末段，可采用准确度更高的测量标准、改善环境条件、增加测量次数或改变测量方法以降低U，再重新评定。不能假定多次平均会消除全部不确定度分量。原始数值保留，不能要求机构改写合格数据。

在本流程中，“待定区”是技术状态，不是最终表的“待补”占位词。若要出具正式记录，写明该项目尚不能判定符合性的具体数值及原因，不选择其已满足用途；关键问题应先处理。另行采用其他有依据的风险规则须显式记录，不能追溯伪称符合JJF判据。设备限用仍须有独立的实际用途证据，不由待定自动生成。
