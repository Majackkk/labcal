# 外部资料迁入

迁入工具读取外部项目的来源登记、候选方案和证书资料，按明确实验室归档；不改写原来源项目，也不继承历史技术批准。

使用`./labcal migrate-legacy --help`查询输入参数。真实迁入前，应明确资料授权、归属、设备身份及版本。共享参考资料与实验室专有资料分开接入。

迁入的限值和引用只保存为候选原文，不能直接转换成核验通过的规则。使用前依据原页、实际配置和检测用途逐项整理，再记录具体用户确认。

相同原件和方案内容复用已有身份及版本；新证据或技术变更建立新版本，不覆盖原件、已确认内容和历史输出。

迁移报告及缺口清单属于本地业务资料，不随源码分发。用`./labcal source gaps --help`查看原件缺口查询方式；工程验证不能替代原件核实及真实业务确认。
